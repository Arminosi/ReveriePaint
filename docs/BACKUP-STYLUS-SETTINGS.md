# 数位笔设置的独立备份与恢复

原分类只识别旧 `stylus_` 前缀和 `pressure_curve`，遗漏当前品牌侧键、通用笔、
全局压感等实际键名，导致它们进入通用设置，而没有进入用户选择的数位笔模块。

`BackupPreferenceKeys` 集中声明实际数位笔键，两个导出模块据此互斥分类，数量统计同步更新。
保留旧键名读取；避免用整个品牌前缀分类，以免误收未来新增的无关设置。
恢复后调用已有设置同步入口刷新 VM、压感及驱动，再加载快捷键。
同时补上 `genericSideButtonErase` 的偏好读取，保证恢复和重启时不丢失关闭状态。

格式版本仍为 1，旧备份中数位笔值若在通用设置条目，仍随该模块恢复；
旧版本未导出的值无法恢复。以后新增数位笔偏好时需同步集合与测试。
本次不修改手写笔事件识别，也不包含恢复文件的原子替换修正。

## 验证范围与待测项

JVM 测试覆盖各品牌代表字段、数据类型往返、模块隔离以及旧备份读取。
不能用序列化测试代替真实设置页、驱动及实体笔验证。
尚未完成本轮真机回归，请维护者补测：

1. 设置通用笔两个不同侧键动作、关闭按住侧键擦除、自定义压感曲线，只备份数位笔模块。
2. 修改成另一组值后恢复，检查无需重启，页面显示和实体笔行为立即恢复。
3. 结束后台并重开，确认恢复值仍保留。
4. 仅恢复通用设置，不应覆盖数位笔绑定；两个模块一起恢复应均生效。
5. 完整恢复旧版本备份，确认通用设置条目中的数位笔字段仍可读取。

各品牌按键行为需对应实体笔复查；本次不宣称修复 Ugee/XP-Pen 事件映射。
