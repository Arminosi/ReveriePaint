# 猫猫 3D 资产重做 (重拓扑 + 真实猫骨架)

> 状态: **规格已冻结, 待执行**
> 起因: 现有 `anime_cat.glb` 是 Meshy 导出的网格 (12308 顶点 / 9484 三角形, 9550 个唯一位置,
> 明显是碎壳拼的) + 一套与猫解剖不匹配的骨架 (颈骨 0.41 长、Chest 骨 0.17 长且朝前下、
> 股骨静止时朝下)。结果是:
> - 端坐/蜷缩这类姿态要么腿在空中划水, 要么必须把股骨翻 155° (线性混合蒙皮直接塌成一团);
> - 蜷缩团不成球 —— 腿长 + 颈长 + 脊柱只有一段中段骨, 几何上做不到。

## 1. 验收标准 (先定判据, 再动手)

新资产必须同时满足下面 6 条, 任何一条不过就不换进包里:

| # | 判据 | 怎么量 |
|---|---|---|
| A1 | **蜷缩成球**: 侧视轮廓高度 ≤ 0.62 × 长度, 头收到前爪之间, 背部拱起 35°~50° | `preview_cat_poses.py` 打印的轮廓高度/长度 |
| A2 | **端坐**: 前腿竖直、骨盆坐到后跗关节上、头抬平 | 同上 + Blender 侧视/四分之三视对照图 |
| A3 | **单骨局部角 ≤ 75°** 覆盖全部 9 个预设 (超了蒙皮必塌) | `cat_pose_solver.py` 打印的逐骨角 |
| A4 | **无面拉伸**: 边长拉伸 p99 ≤ 1.35, max ≤ 1.8 (只统计 L0 > 0.008 的边) | `preview_cat_poses.py --stretch` |
| A5 | **静止姿态零形变**: `world × inverseBind ≈ I` 误差 < 1e-5, 权重和 = 1 | `Model3DTest`, `SkeletonPoseTest` |
| A6 | **贴地点正确**: 最低 1cm 内的顶点所属骨必须是爪/跗关节/腹部, 不能是耳朵/吻部/尾巴 | `preview_cat_poses.py` 打印 |

## 2. 骨架设计 (34 关节)

比例基准: 身长 (鼻到尾根) = 1.0, 站立肩高 ≈ 0.52, 头长 ≈ 0.22。
**颈只留 1 段、长度 ≤ 0.10**, 这是这次重做的核心差异 —— 长颈是"看着惊悚"的主要来源。

```
root (骨盆)
└ spine_01 → spine_02 → spine_03 → chest → neck → head
                                     │              ├ muzzle
                                     │              ├ ear_L / ear_R
                                     │              └ jaw
  ├ hip_L → knee_L → hock_L → meta_L → toe_L
  ├ hip_R → ...
  ├ tail_01 ... tail_06                    (6 段, 每段 ≤ 0.09, 便于卷成圈)
  └ (前肢挂在 chest)
      scapula_L → shoulder_L → elbow_L → carpus_L → toe_FL
      scapula_R → ...
```

- 躯干 **5 段** (spine_01..03 + chest), 每段 ≤ 0.16: 蜷缩时每段弯 25° 即可拱出 50° 而不塌;
- 尾 **6 段**: 才能真正绕体一周 (现有 5 段长度 0.13~0.18, 转弯半径太大);
- 命名沿用 `build_cat_glb.py` 的约定 (局部 X = 世界 +X, 骨长方向 = 局部 Y), 这样
  `Skeleton3D` 的俯仰线性可加前提继续成立, `cat_pose_solver.py` 不用改;
- 语义键: `PosePresets.CAT_SEMANTIC_KEYS` 增加 `cat_spine_01/02/03`, 面板给"弓背"一个滑杆
  (三根骨按比例联动), 不要再暴露 5 个独立滑杆。

## 3. 网格策略

以现有 GLB 为**轮廓参照**在 Blender 里重建, 不直接 remesh (voxel remesh 会吃掉胡须和耳尖):

1. 镜像建模低多边形猫身 (quad 为主), 目标 **3~5k 三角形**, 比例按 §2 基准;
2. 耳/胡须/眼作为独立小壳体后合并 (各自权重绑到 ear/head 骨);
3. 平滑着色 + 法线统一朝外; 不加贴图 (App 只吃顶点色/单色);
4. 中线对称 (x=0 镜像), 便于左右权重对称;
5. 导出 glTF: `export_apply=False, export_yup=True, export_skins=True, export_materials='NONE'`;
6. 居中到原点、脚掌落在 y = 绑定姿态最低点上。

## 4. 蒙皮策略

沿用 `build_cat_glb.py` 已验证的算法, 但加两条:

- 距离权重 `1/(d+0.03)³` 取前 4 + **25 轮**网格平滑 (段数变多, 需要更强的平滑才不出现折痕);
- **关节体积保持**: 对膝/肘/跗关节, 在大角度下用 dual-quaternion 的近似补偿 (或用 Blender 的
  "Preserve Volume"), 这一条是让 75° 折角不塌的关键; 若实现成本过高, 退化为"每关节权重窗
  收紧 + 骨长补偿 3%"。

## 7. 已知取舍

  (网格顶点数不变时, 多段脊柱仍受限于躯干只有 ~200 个顶点, 蜷缩会显得棱角) —— 作为 plan B。
