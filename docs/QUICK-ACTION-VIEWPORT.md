# 画布缩放与旋转快捷操作

关联问题：[#120](https://github.com/LanRhyme/ReveriePaint/issues/120)

## 问题与处理

快捷操作浮窗原来只有锁定、翻转和回正等视图操作，没有放大、缩小和小角度旋转。
模拟器或鼠标用户因此需要依赖键盘或多指手势，原有键盘旋转又是每次 90°。

本次在已有 `QuickAction` 动作列表中增加四项：放大画布、缩小画布、左转 15°、右转 15°。
用户在快捷操作浮窗的设置中自行添加、排序或移除；默认动作列表不变。
三指菜单与自定义顶栏共享这份可选动作列表，所以也能选择这四项，各入口的配置仍独立保存。

缩放沿用键盘操作的 1.2 倍步长，缩小使用倒数；范围与触摸画布一致，为相对适配比例的
0.02～128 倍。旋转是在当前角度上加减 15°，不会先吸附到 15° 的整数倍。
视图锁定时忽略这些变换并提示锁定；绘画或多指手势尚未结束时不插入新的视图变换。
键盘现有的缩放、90° 旋转及其快捷键配置保留。

## 实现与原因

- `QuickAction` 使用字符串 ID 持久化，新增动作不迁移或重排已有配置
- ViewModel 只发送 UI 命令，视口仍由 `PaintingPage` 与 `CanvasTouchView` 管理
- `CanvasViewportStep` 计算离散步进，以当前视图中心为锚点同步变换平移量，避免已经平移的画布越缩越偏
- 缩放到上下限时按实际生效倍率补偿平移，重复点击不再漂移；屏幕空间的补偿也适用于已旋转或镜像的视图
- 通过已有 `applyViewTransform` 入口取消回正与吸附动画，防止后续动画帧覆盖快捷操作
- 只改变视口，不修改图层像素、文档尺寸、撤销记录或录制格式；没有 JNI 或原生库改动

## 验证范围

新增 JVM 测试覆盖视图中心锚点、镜像/旋转组合、缩放边界、反向恢复、旋转整圈、
视图锁定和非法输入、旧键盘命令隔离，以及三指菜单新旧配置的序列化兼容。
编译、全量测试及设备验证的实际结果另记于本轮交接和 PR，不将这些测试步骤视为已完成验证。

## 手动回归

1. 打开画布和快捷操作浮窗，进入设置，添加四个新动作并调整顺序；确认旧配置没有自动插入新按钮
2. 画一个中心标记，将它平移到视图中心，点击放大/缩小；预期中心标记不漂移，两种操作各一次恢复原比例
3. 从 0° 连点右转六次应到 90°，左转六次回到 0°；从手动旋转后的任意角度点击，预期增减 15°
4. 在已经平移、旋转和水平/垂直镜像的情况下重复操作，检查中心锚点与旋转方向
5. 连续缩放至上下限，继续点击不应反向跳变或平移；点居中回正，动画期间再点旋转，结果不应被旧动画覆盖
6. 开启视图锁定，四项操作均不改变视图且提示锁定；解锁后恢复
7. 将动作分别添加到三指菜单和自定义悬浮顶栏，检查执行、移除与独立排序；退出重进检查配置保留
8. 开启按钮文字标签，检查中英文、横竖屏和手机/平板布局；键盘原有 R 键仍按 90° 旋转
9. 变换视图后继续绘画，笔尖位置应与落墨一致；撤销应只撤销笔画，不撤销视图变化

## 后续维护

新增步进命令与键盘旧命令刻意分开。未来若统一键盘的缩放边界、锁定策略或旋转步长，
需要独立评估已有快捷键用户的行为变化，不宜顺便改变。
浮窗、顶栏与三指菜单共用执行入口，修改时需一起回归。
